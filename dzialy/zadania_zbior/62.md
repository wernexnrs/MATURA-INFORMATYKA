## 62.1

```py
liczby = []

with open("liczby1.txt") as file:
    for line in file:
        liczby.append(int(line, 8))

print("min:", oct(min(liczby))[2:], "max:", oct(max(liczby))[2:])
```
**Odpowiedź:** najmniejsza: 1002, największa: 777044

## 62.2

```py
liczby = []

with open("liczby2.txt") as file:
    for line in file:
        liczby.append(int(line))

dlugosc = 1
poczatek = 0
najdluzszy = 1
najlepszy_poczatek = 0

for i in range(1, len(liczby)):
    if liczby[i] >= liczby[i - 1]:
        dlugosc += 1
    else:
        dlugosc = 1
        poczatek = i
    if dlugosc > najdluzszy:
        najdluzszy = dlugosc
        najlepszy_poczatek = poczatek

print(liczby[najlepszy_poczatek], najdluzszy)
```
**Odpowiedź:** pierwszy element: 639, liczba elementów: 6

## 62.3

```py
rowne = 0
wieksze = 0

with open("liczby1.txt") as file1:
    with open("liczby2.txt") as file2:
        for x, y in zip(file1, file2):
            x = int(x, 8)  # liczby1.txt - zapis ósemkowy
            y = int(y)  # liczby2.txt - zapis dziesiętny
            if x == y:
                rowne += 1
            elif x > y:
                wieksze += 1

print("a)", rowne)
print("b)", wieksze)
```
**Odpowiedź:** a) 160, b) 357

> W pliku `wyniki.txt` z oficjalnych rozwiązań CKE w podpunkcie a) jest 639, ale algorytm wzorcowy CKE (`zadanie 3.cc`, taki sam jak powyżej) daje na tych danych 160 – liczba 639 to omyłkowo przepisany wynik zadania 62.2.

## 62.4

```py
dziesietnie = 0
osemkowo = 0

with open("liczby2.txt") as file:
    for line in file:
        liczba = int(line)
        dziesietnie += str(liczba).count("6")
        osemkowo += oct(liczba)[2:].count("6")

print("dziesiętnie:", dziesietnie)
print("ósemkowo:", osemkowo)
```
**Odpowiedź:** w zapisie dziesiętnym: 411, w zapisie ósemkowym: 625

> W pliku `wyniki.txt` CKE wartości są zamienione miejscami (dziesiętnie 625, ósemkowo 411) – program wzorcowy CKE (`zadanie 4.cc`) wypisuje najpierw wynik ósemkowy, a potem dziesiętny.
