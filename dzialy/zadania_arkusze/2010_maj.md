## 1a

> **Treść zadania:** Szyfr przestawieniowy: tekst wpisujemy wierszami do kwadratowej tablicy n × n, a szyfrogram odczytujemy kolumnami od lewej do prawej. Wymiar n to najmniejsza liczba, przy której cały tekst mieści się w tablicy; wolne pola uzupełnia się znakami odstępu (oznaczanymi `_`).
>
> Przykład: `ALGORYTM_PRZESTAWIENIOWY` (24 znaki) → tablica 5 × 5 → `AYRAILTZWOGMEIWO_SEYRPTN_`.
>
> Podaj wzór (lub algorytm) wyznaczający liczbę wierszy i kolumn tablicy dla tekstu o długości d znaków.

```py
from math import ceil, sqrt


def wymiar(d):
    # najmniejsze n, dla którego n * n >= d, czyli n = sufit(pierwiastek(d))
    n = ceil(sqrt(d))
    while n * n < d:  # zabezpieczenie przed błędem zaokrąglenia
        n += 1
    return n


print(wymiar(24), wymiar(25), wymiar(26))
```

## 1b i 1c

> **Treść zadania:** Szyfr przestawieniowy z zadania 1a (tekst wpisywany wierszami do tablicy n × n, odczytywany kolumnami).
>
> - 1b — Rozszyfruj cytat z Sokratesa zaszyfrowany tą metodą — szyfrogram (64 znaki, czyli tablica 8 × 8) jest podany w arkuszu.
> - 1c — Zapisz algorytm szyfrujący tą metodą. Dane: d — długość tekstu, `tekst[1..d]` — znaki tekstu. Wynik: s — długość szyfrogramu, `szyfr[1..s]` — znaki szyfrogramu.

```py
from math import ceil, sqrt


def szyfruj(tekst):
    d = len(tekst)
    n = ceil(sqrt(d))
    while n * n < d:
        n += 1
    s = n * n
    tekst = tekst + "_" * (s - d)  # puste pola uzupełniamy znakami odstępu
    szyfr = ""
    for kolumna in range(n):  # odczyt kolumnami
        for wiersz in range(n):
            szyfr += tekst[wiersz * n + kolumna]
    return szyfr


# c) przykład z treści
print(szyfruj("ALGORYTM_PRZESTAWIENIOWY"))
```

```cpp
std::vector<std::string> znaki(const std::string& tekst) {
```

## 2a i 2b

> **Treść zadania:** W tablicy `a[1..1023]` zapisano ciąg zer i jedynek tak, że wszystkie zera poprzedzają jedynki (mogą wystąpić same zera albo same jedynki). Dany jest niepełny algorytm liczenia zer:
>
> ```
> liczba_zer ← 0
> l ← 1, p ← 1023
> dopóki l ≤ p wykonuj
>     s ← (l + p) div 2
>     jeżeli a[s] = 1 to p ← s − 1
>     w przeciwnym przypadku
>         liczba_zer ← liczba_zer + .....
>         l ← .....
> ```
>
> - 2a — Uzupełnij brakujące wyrażenia tak, aby algorytm zawsze poprawnie liczył zera.
> - 2b — Ile razy wykonywane jest przypisanie `s ← (l + p) div 2` w każdym przebiegu algorytmu? Uzasadnij.

```py
def liczba_zer(a):
    # a[1..1023], a[0] nieużywane - indeksy jak w zadaniu
    przypisania_s = 0
    zera = 0
    l, p = 1, len(a) - 1
    while l <= p:
        s = (l + p) // 2
        przypisania_s += 1
        if a[s] == 1:
            p = s - 1
        else:
            zera = zera + (s - l + 1)  # zera na pozycjach l..s
            l = s + 1
    return zera, przypisania_s


# sprawdzenie dla wszystkich możliwych tablic (k zer, potem jedynki)
liczby_przypisan = set()
for k in range(1024):

    if zera != k:
        print("błąd dla", k)
    liczby_przypisan.add(przypisania_s)
print(liczby_przypisan)
```

```java
import java.util.*;

public class Zadanie {
    static int[] liczbaZer(int[] a) {
        // a[1..1023], a[0] nieużywane - indeksy jak w zadaniu
        int przypisaniaS = 0;
        int zera = 0;
        int l = 1, p = a.length - 1;
        while (l <= p) {
            int s = (l + p) / 2;
            przypisaniaS += 1;
            if (a[s] == 1) {
                p = s - 1;
            } else {
                zera = zera + (s - l + 1); // zera na pozycjach l..s
                l = s + 1;
            }
        }
        return new int[]{zera, przypisaniaS};
    }

    public static void main(String[] args) throws Exception {
        // sprawdzenie dla wszystkich możliwych tablic (k zer, potem jedynki)

        for (int k = 0; k < 1024; k++) {
            int[] a = new int[1024]; // a[0] nieużywane
            for (int i = k + 1; i < 1024; i++) {
                a[i] = 1;
            }
            int[] wynik = liczbaZer(a);
            if (wynik[0] != k) {
                System.out.println("błąd dla " + k);

        var napisy = new ArrayList<String>();

    }
}
```

```cpp
#include <print>
```

## 5e

*Zadanie na arkusz kalkulacyjny — rozwiązanie w Pythonie.*

> **Treść zadania:** Dane z pliku `pesel.txt`.
>
> Zestaw liczby osób urodzonych w kolejnych dziesięcioleciach: latach 50., 60., 70., 80. i 90. (np. lata 50. to roczniki 1950–1959 włącznie). Wykonaj wykres przedstawiający procentowy rozkład liczby osób w tych przedziałach.

```py
dekady = {"50": 0, "60": 0, "70": 0, "80": 0, "90": 0}

with open("pesel.txt") as file:
    for line in file:
        dekady[line[0] + "0"] += 1

wszyscy = sum(dekady.values())
for dekada in dekady:
    procent = dekady[dekada] / wszyscy * 100
    print(f"{dekada}-te {dekady[dekada]} {procent:.1f}%")
```

```cpp
// C++23
#include <fstream>
#include <map>
#include <print>
#include <string>

int main() {
    std::map<std::string, int> dekady = {{"50", 0}, {"60", 0}, {"70", 0}, {"80", 0}, {"90", 0}};
    std::ifstream plik("pesel.txt");
    std::string pesel;
    while (plik >> pesel) {
        dekady[pesel.substr(0, 1) + "0"] += 1;
    }
    int wszyscy = 0;
    for (const auto& [dekada, ile] : dekady) {
        wszyscy += ile;
    }
    for (const auto& [dekada, ile] : dekady) {
        double procent = static_cast<double>(ile) / wszyscy * 100;
        std::println("{}-te {} {:.1f}%", dekada, ile, procent);
    }
}
```

```java
// Java 25
import java.nio.file.*;
import java.util.*;

public class Zadanie {
    public static void main(String[] args) throws Exception {
        var dekady = new LinkedHashMap<String, Integer>();
        for (String d : List.of("50", "60", "70", "80", "90")) {
            dekady.put(d, 0);
        }
        for (String linia : Files.readAllLines(Path.of("pesel.txt"))) {
            String dekada = linia.charAt(0) + "0";
            dekady.put(dekada, dekady.get(dekada) + 1);
        }
        int wszyscy = 0;
        for (int ile : dekady.values()) {
            wszyscy += ile;
        }
        for (var e : dekady.entrySet()) {
            double procent = (double) e.getValue() / wszyscy * 100;
            // Locale.ROOT - kropka dziesiętna niezależnie od ustawień systemu
            System.out.println(String.format(Locale.ROOT, "%s-te %d %.1f%%", e.getKey(), e.getValue(), procent));
        }
    }
}
```

**Odpowiedź:** 50-te 22, 60-te 28, 70-te 36, 80-te 58, 90-te 6 (wykres kołowy z procentami: ok. 15%, 19%, 24%, 39%, 4%)
