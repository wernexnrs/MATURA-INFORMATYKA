## 1.1 i 1.2

> **Treść zadania (n-permutacja):** n-permutacją nazywamy n-elementowy ciąg liczb całkowitych zawierający każdą z liczb 1, 2, …, n dokładnie raz, np. (4,2,1,3) jest 4-permutacją, a (1,3,1,2) czy (2,3,4,5) nie są. W ciągu, który nie jest n-permutacją, można podmienić niektóre elementy, aby nią był – np. w (1,3,1) wystarczy zmienić jedną jedynkę na 2.
>
> - **1.1** — Dla podanych ciągów wpisz najmniejszą liczbę elementów do podmiany (0, jeśli ciąg już jest n-permutacją): n=4 (1,4,2,5); n=5 (2,2,2,2,2); n=4 (4,2,3,1); n=6 (5,4,1,5,6,8); n=6 (8,4,9,6,5,7). Przykład: n=3 (1,3,1) → 1.
> - **1.2** — Zapisz algorytm, który dla tablicy `A[1..n]` dodatnich liczb całkowitych obliczy minimalną liczbę `k` elementów do podmiany, aby powstała n-permutacja. Wolno używać tylko instrukcji sterujących, podstawowych operatorów arytmetycznych (w tym `div`, `mod`), logicznych, porównań, odwołań do elementów tablicy i przypisań – bez funkcji wbudowanych.

```py
def do_podmiany(A):
    n = len(A)
    wystapienia = [0] * (n + 1)   # wystapienia[x] - ile razy liczba x (1..n) jest w A
    k = 0
    for x in A:
        if 1 <= x <= n:
            wystapienia[x] += 1
        else:
            k += 1                # liczba spoza [1, n] na pewno do podmiany
    for x in range(1, n + 1):
        if wystapienia[x] > 1:
            k += wystapienia[x] - 1   # wszystkie powtórzenia poza jednym
    return k
```

```cpp
// C++23
#include <print>
#include <vector>

int do_podmiany(const std::vector<int>& A) {
    int n = A.size();
    std::vector<int> wystapienia(n + 1, 0);  // wystapienia[x] - ile razy liczba x (1..n) jest w A
    int k = 0;
    for (int x : A) {
        if (1 <= x && x <= n)
            wystapienia[x]++;
        else
            k++;  // liczba spoza [1, n] na pewno do podmiany
    }
    for (int x = 1; x <= n; x++)
        if (wystapienia[x] > 1) k += wystapienia[x] - 1;  // wszystkie powtórzenia poza jednym
    return k;
}
```

## 2.1, 2.2 i 2.3

> **Treść zadania:** Dla słowa `s` długości n złożonego z liter `a` i `b` wykonujemy algorytm, którego wynikiem jest `k`:
>
> ```
> A[0] ← 0
> dla i = 1..n:   jeżeli s[i] = 'a' to A[i] ← A[i-1] + 1, w p.p. A[i] ← A[i-1]
> B[n+1] ← 0
> dla j = n..1:   jeżeli s[j] = 'b' to B[j] ← B[j+1] + 1, w p.p. B[j] ← B[j+1]
> k ← 1
> dla i = 0..n:   jeżeli A[i] + B[i+1] > k to k ← A[i] + B[i+1]
> ```
>
> - **2.1** — Podaj wynik k dla słów `aababb` (n=6) i `baabbaaab` (n=9). Przykłady: `aabab` → 4, `ab` → 2, `aaa` → 3.
> - **2.2** — Podaj przykłady dziesięcioliterowych słów, dla których k = 10 oraz k = 5.
> - **2.3** — Zapis aᵐ (bᵐ) oznacza literę a (b) powtórzoną m razy. Podaj wynik k dla słowa a³⁰⁰b⁵⁵⁰a³⁰⁰b⁷a²⁸⁰b¹¹⁰.

```py
def algorytm(s):
    n = len(s)
    s = " " + s                   # indeksowanie od 1 jak w treści
    A = [0] * (n + 2)
    for i in range(1, n + 1):
        if s[i] == "a":
            A[i] = A[i - 1] + 1
        else:
            A[i] = A[i - 1]
    B = [0] * (n + 2)
    for j in range(n, 0, -1):
        if s[j] == "b":
            B[j] = B[j + 1] + 1
        else:
            B[j] = B[j + 1]
    k = 1
    for i in range(0, n + 1):
        if A[i] + B[i + 1] > k:
            k = A[i] + B[i + 1]
    return k
```

```cpp
// C++23
#include <fstream>
#include <print>
#include <string>
#include <utility>
#include <vector>

std::vector<long long> liczby;

// 4.2 - zwraca (liczba wszystkich czynników pierwszych, liczba różnych czynników)
std::pair<int, int> czynniki(long long x) {
    int wszystkie = 0;
    int rozne = 0;
    for (long long d = 2; d * d <= x; d++) {
        if (x % d == 0) {
            rozne++;
            while (x % d == 0) {
                x /= d;
                wszystkie++;
            }
        }
    }
    if (x > 1) {
        wszystkie++;
        rozne++;
    }
    return {wszystkie, rozne};
}

// dobre piątki - liczymy rekurencyjnie łańcuchy podzielności długości 5
long long lancuchy(long long ostatnia, int dlugosc) {
    if (dlugosc == 5) return 1;
    long long wynik = 0;
    for (long long nastepna : liczby)
        if (nastepna != ostatnia && nastepna % ostatnia == 0) wynik += lancuchy(nastepna, dlugosc + 1);
    return wynik;
}

int main() {
    std::ifstream plik("liczby.txt");
    long long a;
    while (plik >> a) liczby.push_back(a);

    // 4.1
    int ile = 0;
    long long pierwsza = 0;
    for (long long x : liczby) {

        if (napis.front() == napis.back()) {
            if (ile == 0) pierwsza = x;

        }
```
