## 1a

> **Treść zadania:** Zadanie 1. Liczba binarna. Kod uzupełnień do jedności (U1): liczbę nieujemną zapisujemy binarnie i dopisujemy na początku bit znaku 0; liczbę ujemną zapisujemy binarnie, negujemy każdy bit i dopisujemy na początku bit znaku 1. Przykład: `9 = 01001 (U1)`, `-9 = 10110 (U1)`, a `0 = 00 (U1)`.
>
> Zapisz w kodzie U1 liczby dziesiętne `46` oraz `-46`.

```py
def na_u1(x):
    binarnie = bin(abs(x))[2:]
    if x >= 0:
        return "0" + binarnie
    # liczba ujemna: negacja bitów zapisu wartości bezwzględnej i bit znaku 1
    negacja = ""
    for bit in binarnie:
        if bit == "0":
            negacja += "1"
        else:
            negacja += "0"
    return "1" + negacja


print(na_u1(9), na_u1(-9))  # przykład z treści: 01001 10110
print(na_u1(46), na_u1(-46))
```

## 1b i 1c

> **Treść zadania:** Kod U1 jak w zadaniu 1a (bit znaku na początku; dla liczb ujemnych pozostałe bity są zanegowanym zapisem binarnym wartości bezwzględnej).
>
> - 1b — zamień liczby zapisane w U1: `0100111` oraz `1001101` na system dziesiętny.
> - 1c — zapisz algorytm obliczający wartość liczby zapisanej w U1. Dane: `d` — długość zapisu (`d ≥ 1`), tablica `bin[1..d]` z bitami zapisu, gdzie `bin[1]` to bit znaku. Wynik: `x` — wartość liczby. Przykład: dla `d = 5` i `bin = 10110` wynikiem jest `x = -9`.

```py
def z_u1(bin):
    # bin[0] to bit znaku (w zadaniu bin[1])
    d = len(bin)
    bity = list(bin)
    if bity[0] == "1":  # liczba ujemna - negujemy bity wartości
        for i in range(1, d):
            if bity[i] == "1":
                bity[i] = "0"
            else:
                bity[i] = "1"
    x = 0
    for i in range(1, d):
        x = x * 2 + int(bity[i])
    if bity[0] == "1":
        x = -x
    return x


print(z_u1("10110"))  # przykład z treści: -9
print(z_u1("0100111"), z_u1("1001101"))
```
