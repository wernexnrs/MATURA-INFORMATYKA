## 1a

> **Treść zadania:** Zadanie 1. Korale. Rekurencyjna procedura `Korale(n)` dla dodatniej liczby całkowitej `n`:
> ```
> Korale(n):
>     jeżeli n = 1: nawlecz czarny koralik na prawy koniec sznurka; zakończ
>     jeżeli n parzyste: Korale(n/2); nawlecz biały koralik na prawy koniec; zakończ

> **Treść zadania:** Bisekcja jak w zadaniu 2. Dane są: przedział domknięty `<a, b>`, funkcja `f` ciągła na nim, taka że `f(a)·f(b) < 0`, oraz dodatnia dokładność `d ≤ b − a`. Zapisz algorytm wyznaczający metodą bisekcji przybliżenie miejsca zerowego `f` w `<a, b>` z dokładnością `d`.

```py
def bisekcja(f, a, b, d):
    x = (a + b) / 2
    while b - a >= d:
        if f(x) == 0:
            return x
        if f(a) * f(x) < 0:
            b = x
        else:
            a = x
        x = (a + b) / 2
    return x


print(bisekcja(lambda x: x ** 3 - x - 2, 0, 2, 0.0001))
```

```cpp

double bisekcja(std::function<double(double)> f, double a, double b, double d) {
    double x = (a + b) / 2;

        if (f(x) == 0) return x;
        if (f(a) * f(x) < 0) b = x;
        else a = x;
        x = (a + b) / 2;
    }
    return x;
}
```

> ```
> jeżeli n = 1: suma ← 1
> w przeciwnym razie:
>     suma ← 1 + n; i ← n - 1
>     dopóki i > 1: suma ← 1 + i * suma; i ← i - 1
> ```
>
> Podaj wartość zmiennej `suma` po zakończeniu algorytmu dla `n = 4` i `n = 6`.

```py
def algorytm(n):
    if n == 1:
        return 1
    suma = 1 + n
    i = n - 1
    while i > 1:
        suma = 1 + i * suma
        i -= 1
    return suma


print(algorytm(4), algorytm(6))
```

```cpp
// C++23
#include <print>

long long algorytm(int n) {
```
