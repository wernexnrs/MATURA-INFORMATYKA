## 1.1 i 1.2

> **Treść zadania:** Zadanie 1 (analiza algorytmu). Dla liczby całkowitej dodatniej `n` algorytm wyznacza liczbę całkowitą dodatnią `p` (div oznacza dzielenie całkowite):
>
> ```
> p ← 1
> q ← n
> dopóki p < q wykonuj
>     s ← (p + q) div 2
>     (*) jeżeli s*s*s < n
>             p ← s + 1
>         w przeciwnym wypadku
>             q ← s
> ```
>
> - 1.1 — podaj wynik `p` dla `n` = 28, 64 i 80.
> - 1.2 — podaj najmniejszą i największą liczbę `n`, dla której wynikiem algorytmu jest `p = 10`.

```py
def algorytm(n):
    p = 1
    q = n
    while p < q:
        s = (p + q) // 2
        if s * s * s < n:
            p = s + 1
        else:
            q = s
    return p


# 1.1
for n in [28, 64, 80]:
    print(n, algorytm(n))

# 1.2 - najmniejsze i największe n, dla którego p = 10
liczby = [n for n in range(1, 2000) if algorytm(n) == 10]
print(min(liczby), max(liczby))
```

def skrajnie_lewy(n, X, Y):
    k = 0
    for i in range(1, n):
        if X[i] / Y[i] < X[k] / Y[k]:
            k = i
    return X[k], Y[k]

## 2.2

> **Treść zadania:** Dane jak w zadaniu 2.1: tablice `X[1..n]`, `Y[1..n]` ze współrzędnymi szczytów (`Y[i] > 0`), żadne dwa nie leżą w jednej linii z obserwatorem w (0,0).
>
> Napisz algorytm, który przestawi elementy tablic `X` i `Y` tak, aby szczyty były uporządkowane w kolejności widzenia ich przez obserwatora od lewej do prawej (rosnąco względem `X[i]/Y[i]`). Złożoność co najwyżej kwadratowa; wolno używać tylko instrukcji sterujących, operatorów arytmetycznych i logicznych, porównań i przypisań — bez funkcji bibliotecznych (np. gotowego sortowania).

```py
def sortuj_szczyty(n, X, Y):
    # sortowanie przez wybór - złożoność kwadratowa
    for i in range(n - 1):
        m = i
        for j in range(i + 1, n):
            if X[j] / Y[j] < X[m] / Y[m]:
                m = j
        X[i], X[m] = X[m], X[i]
        Y[i], Y[m] = Y[m], Y[i]


X = [3, -2, 5, -4]
Y = [4, 3, 2, 1]
sortuj_szczyty(len(X), X, Y)
print(X)
print(Y)
```

void sortuj_szczyty(int n, std::vector<int>& X, std::vector<int>& Y) {
    // sortowanie przez wybór - złożoność kwadratowa
    for (int i = 0; i < n - 1; i++) {
        int m = i;
        for (int j = i + 1; j < n; j++)
            if ((double)X[j] / Y[j] < (double)X[m] / Y[m])
                m = j;

        std::swap(Y[i], Y[m]);
    }
}

    std::vector<int> Y = {4, 3, 2, 1};
    sortuj_szczyty(X.size(), X, Y);

    std::println("{}", Y);
}

import java.util.Arrays;

public class Zadanie {
    static void sortujSzczyty(int n, int[] X, int[] Y) {
        // sortowanie przez wybór - złożoność kwadratowa
        for (int i = 0; i < n - 1; i++) {
            int m = i;
            for (int j = i + 1; j < n; j++)
                if ((double) X[j] / Y[j] < (double) X[m] / Y[m])
                    m = j;
            int t = X[i]; X[i] = X[m]; X[m] = t;
            t = Y[i]; Y[i] = Y[m]; Y[m] = t;
        }
    }

    public static void main(String[] args) throws Exception {
        int[] X = {3, -2, 5, -4};
        int[] Y = {4, 3, 2, 1};
        sortujSzczyty(X.length, X, Y);
        System.out.println(Arrays.toString(X));
        System.out.println(Arrays.toString(Y));
    }
}

import java.nio.file.Files;

> **Treść zadania:** Dane z pliku `woda.txt` (data i dobowy dopływ wody w m³, lata 2008–2017). Cykl pracy zbiornika:

> 4. W ciągu doby do zbiornika dopływa woda z rzeki zgodnie z danymi.
>
> Pomiar 2008-01-01 wskazał 500 000 m³ (kontrolnie: pomiar 2008-02-01 wskazał 338 406 m³). Podaj:
> - a) dzień, w którym pierwszy raz wypuszczono nadmiar wody po przepełnieniu,
> - b) w ilu dniach okresu 2008-01-01 – 2017-12-31 pomiar wykazał co najmniej 800 000 m³,
> - c) największą objętość wody w momencie pomiaru w tym okresie, gdyby zrezygnować z wypuszczania nadmiaru (zbiornik o nieograniczonej pojemności; 2% nadal wypuszczane).
