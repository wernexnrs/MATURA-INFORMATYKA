Funkcja rekurencyjna sklej(n) wyznacza, dla liczby naturalnej n > 0, długość napisu powstałego ze sklejenia zapisów binarnych liczb naturalnych od 1 do n − 1:

Kod
krok 1. jeśli n = 1, to wynikiem jest 0 (koniec)
krok 2. jeśli n parzyste, to wynikiem jest n − 1 + 2 · sklej(n / 2)
krok 3. jeśli n nieparzyste, to wynikiem jest n − 1 + sklej((n − 1) / 2) + sklej((n + 1) / 2)

Wykonanie funkcji można przedstawić jako drzewo wszystkich wywołań rekurencyjnych (w arkuszu podano drzewo dla sklej(5): korzeń ma dzieci sklej(2) i sklej(3) itd.). Narysuj analogiczne drzewo wywołań dla sklej(7).

Python
# drzewo wywołań - każde wywołanie wypisane z wcięciem równym głębokości rekurencji
def drzewo(n, glebokosc=0):
    print("    " * glebokosc + f"sklej({n})")
    if n == 1:
        return
    if n % 2 == 0:
        drzewo(n // 2, glebokosc + 1)
    else:
        drzewo((n - 1) // 2, glebokosc + 1)
        drzewo((n + 1) // 2, glebokosc + 1)


drzewo(7)

    std::string wciecie = "";

    }
}

}

Funkcja sklej(n) jak w 1a.

Podaj algorytm bez rekurencji (bez wywoływania sklej), który wypełnia tablicę s[1..n] tak, że s[i] = sklej(i) dla 1 ≤ i ≤ n. Wskazówka: przy liczeniu s[i] można korzystać z obliczonych już wartości s[1], …, s[i − 1]. Dane: liczba naturalna n > 0. Wynik: tablica s[1..n].

Python
def wypelnij(n):
    # s[1..n], s[i] = sklej(i), bez rekurencji
    s = [0] * (n + 1)
    s[1] = 0
    for i in range(2, n + 1):
        if i % 2 == 0:
            s[i] = i - 1 + 2 * s[i // 2]
        else:
            s[i] = i - 1 + s[(i - 1) // 2] + s[(i + 1) // 2]
    return s


s = wypelnij(10)
print(s[1:])

# sprawdzenie: s[n] to długość sklejonych zapisów binarnych liczb od 1 do n-1
for n in range(1, 11):
    napis = ""
    for i in range(1, n):
        napis += bin(i)[2:]
    print(n, s[n], len(napis))

std::vector<int> wypelnij(int n) {
    // s[1..n], s[i] = sklej(i), bez rekurencji
    std::vector<int> s(n + 1, 0);
    s[1] = 0;
    for (int i = 2; i <= n; i++) {
        if (i % 2 == 0) {
            s[i] = i - 1 + 2 * s[i / 2];
        } else {
            s[i] = i - 1 + s[(i - 1) / 2] + s[(i + 1) / 2];
        }
    }
    return s;
}

int main() {
    std::vector<int> s = wypelnij(10);
    std::println("{}", std::vector<int>(s.begin() + 1, s.end())); // s[1:]

    // sprawdzenie: s[n] to długość sklejonych zapisów binarnych liczb od 1 do n-1
    for (int n = 1; n < 11; n++) {
        std::string napis = "";
        for (int i = 1; i < n; i++) {
            napis += std::format("{:b}", i); // zapis dwójkowy
        }
        std::println("{} {} {}", n, s[n], napis.size());
    }
}

Algorytm szybkiego potęgowania: dla liczby rzeczywistej a i naturalnej n ≥ 0 oblicza p = aⁿ.

Kod
krok 1. p := 1, b := a
krok 2. dopóki n > 0 wykonuj:
    a) jeśli n mod 2 = 1, to p := p * b
    b) b := b * b
    c) n := n div 2

Uzupełnij tabelę wartości zmiennych p, b, n po kolejnych wykonaniach kroku 2 dla dowolnego a i początkowego n = 12 (pierwszy wiersz: 1, a, 12).

Python · zamiast wartości pamiętamy wykładniki: p = a^wp, b = a^wb

    wb = wb + wb      # b := b * b
    n = n // 2
    print(f"p = a^{wp}, b = a^{wb}, n = {n}")

Algorytm potęgowania z zadania 2a; liczymy mnożenia, czyli wykonania instrukcji p := p * b oraz b := b * b.

  • 2b — Podaj liczbę wszystkich mnożeń wykonywanych przez algorytm dla n = 2, 3, 4, 5, 6, 7.
  • 2c — Wskaż funkcję równą liczbie mnożeń dla n będącego potęgą dwójki; do wyboru: f(n) = 2 + log₂n, f(n) = 1 + n, f(n) = 2n² − 1, f(n) = 2ⁿ.
Python
def liczba_mnozen(n):
    mnozenia = 0
    while n > 0:
        if n % 2 != 0:
            mnozenia += 1  # p := p * b
        mnozenia += 1      # b := b * b
        n = n // 2
    return mnozenia


# b)
for n in range(2, 8):
    print(n, liczba_mnozen(n))

# c) dla n będącego potęgą dwójki
for k in range(6):
    print(2 ** k, liczba_mnozen(2 ** k), 2 + k)
