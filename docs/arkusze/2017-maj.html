Zadanie 1. Prostokąt. Dane są: liczba całkowita n > 1, zbiór A zawierający n różnych dodatnich liczb całkowitych oraz liczba pierwsza p. Szukamy największego pola prostokąta, którego sąsiednie boki mają różne długości należące do A (prostokąt nie może być kwadratem), a pole nie jest podzielne przez p. Jeśli takiego prostokąta nie ma, wynikiem jest 0.

  • 1.1 — Oblicz to pole dla danych: A = {7, 5, 11, 33}, p = 3 (odpowiedź: 77); A = {15, 12, 10, 6, 5, 1}, p = 5; A = {6, 28, 7, 12, 10, 14, 5, 9, 4, 8, 18}, p = 7; A = {4, 34, 16, 8, 6, 22, 14, 12, 2, 7}, p = 2.
  • 1.2 — Zapisz algorytm, który dla n, tablicy A[1..n] i p oblicza szukane pole S (lub 0). Liczy się złożoność obliczeniowa; wolno używać tylko dodawania, odejmowania, mnożenia, dzielenia całkowitego i reszty z dzielenia.
Python
def najwieksze_pole(A, p):
    # pole a*b nie dzieli się przez liczbę pierwszą p <=> ani a, ani b nie dzieli się przez p,
    # więc wystarczy znaleźć dwie największe (różne) liczby z A niepodzielne przez p
    max1 = max2 = 0
    for a in A:
        if a % p != 0:
            if a > max1:
                max2 = max1
                max1 = a
            elif a > max2:
                max2 = a
    return max1 * max2  # 0, gdy nie ma dwóch takich liczb


# 1.1
print(najwieksze_pole([15, 12, 10, 6, 5, 1], 5))
print(najwieksze_pole([6, 28, 7, 12, 10, 14, 5, 9, 4, 8, 18], 7))
print(najwieksze_pole([4, 34, 16, 8, 6, 22, 14, 12, 2, 7], 2))

Kod
licz(x):
    jeżeli x = 1: wynik 1

  • 2.1 — Podaj licz(x) dla x = 13, 21, 32 (dla x=11 wynik to 2).
  • 2.2 — Jaka jest najmniejsza dodatnia liczba x, dla której obliczenie licz(x) wymaga dokładnie k wywołań funkcji (licząc pierwsze)? Wybierz: A) k², B) 2^(k−1), C) k+1, D) 2^k. (Np. licz(13) wymaga 4 wywołań.)

Python
wywolania = 0


def licz(x):
    global wywolania
    wywolania += 1
    if x == 1:
        return 1
    w = licz(x // 2)
    if x % 2 == 1:
        return w + 1
    return w - 1


# 2.1
for x in [11, 13, 21, 32]:
    print(x, licz(x))

# 2.2 - najmniejsze x wymagające dokładnie k wywołań
for k in range(1, 8):
    x = 1
    while True:
        wywolania = 0
        licz(x)
        if wywolania == k:
            break
        x += 1
    print(k, x, 2 ** (k - 1))

# 2.3
x = 101
while licz(x) != 0:
    x += 1
print(x)

#include <algorithm>
#include <fstream>
#include <map>
#include <print>
#include <string>
#include <utility>
#include <vector>

int main() {
    // NIP -> łączna liczba kg; wektor zachowuje kolejność pierwszego wystąpienia (jak dict w Pythonie)
    std::vector<std::pair<std::string, long long>> klienci;
    std::map<std::string, int> indeks;  // NIP -> pozycja w wektorze

    std::ifstream plik("cukier.txt");
    std::string data, nip;
    long long kg;
    while (plik >> data >> nip >> kg) {
        if (!indeks.contains(nip)) {
            indeks[nip] = klienci.size();
            klienci.push_back({nip, 0});
        }
        klienci[indeks[nip]].second += kg;
    }

    // stable_sort - przy remisie zostaje kolejność pierwszego wystąpienia, jak w sorted()
    std::stable_sort(klienci.begin(), klienci.end(),
                     [](const auto& a, const auto& b) { return a.second > b.second; });
    for (int i = 0; i < 3; i++)
        std::println("{} {}", klienci[i].first, klienci[i].second);
}

C++23
#include <fstream>
#include <map>
#include <print>
#include <string>

int main() {
    std::map<std::string, long long> ceny;  // rok -> cena 1 kg w groszach (liczymy w groszach, żeby uniknąć błędów float)
    std::ifstream cennik("cennik.txt");
    std::string rok, cena;
    while (cennik >> rok >> cena) {
        size_t przecinek = cena.find(',');
        long long zl = std::stoll(cena.substr(0, przecinek));
        long long gr = std::stoll(cena.substr(przecinek + 1));
        ceny[rok] = zl * 100 + gr;
    }

    long long przychod = 0;
    std::ifstream cukier("cukier.txt");
    std::string data, nip;
    long long kg;
    while (cukier >> data >> nip >> kg)
        przychod += kg * ceny[data.substr(0, 4)];

    std::println("{},{:02d}", przychod / 100, przychod % 100);
}

        }

        System.out.println(przychod / 100 + "," + String.format("%02d", przychod % 100));
    }
