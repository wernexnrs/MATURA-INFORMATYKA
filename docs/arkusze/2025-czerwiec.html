1.1, 1.2 i 1.3

PythonC++23Java 25
Treść zadania

Funkcje pomocnicze dla nieujemnej liczby całkowitej x: skróć(x) usuwa ostatnią cyfrę zapisu dziesiętnego (skróć(249) = 24, skróć(5) = 0), dopisz(x) dopisuje na końcu cyfrę 0 (dopisz(29) = 290, dopisz(0) = 0), ostatnia(x) zwraca ostatnią cyfrę (ostatnia(307) = 7). Dla nieujemnych liczb całkowitych a, b dana jest funkcja:

Kod
f(a, b):
    jeżeli b = 0
        wynik 0, zakończ
    k ← ostatnia(b)
    w ← f(a, skróć(b))
    w ← dopisz(w)
    dopóki k > 0 powtarzaj
        w ← w + a
        k ← k − 1
    wynik w
  • 1.1 — Podaj wynik f(a, b) dla par (42, 2), (4, 125), (103, 104).
  • 1.2 — Ile łącznie razy zostanie wywołana funkcja f, jeśli pierwszym wywołaniem jest f(987654321, 123456789)?
  • 1.3 — Ile łącznie razy zostanie wykonana instrukcja w ← w + a, jeśli pierwszym wywołaniem jest a) f(2024, 1000), b) f(2024, 1234)?
Python
def skroc(x):
    return x // 10


def dopisz(x):
    return x * 10


def ostatnia(x):
    return x % 10


wywolania = 0
dodawania = 0


def f(a, b):
    global wywolania, dodawania
    wywolania += 1
    if b == 0:
        return 0
    k = ostatnia(b)
    w = f(a, skroc(b))
    w = dopisz(w)
    while k > 0:
        w = w + a
        dodawania += 1
        k = k - 1
    return w


# 1.1
for a, b in [(42, 2), (4, 125), (103, 104)]:
    print(a, b, f(a, b))

# 1.2
wywolania = 0
f(987654321, 123456789)
print("1.2", wywolania)

# 1.3
for a, b in [(2024, 1000), (2024, 1234)]:
    dodawania = 0
    f(a, b)
    print("1.3", a, b, dodawania)

Treść zadania

Operacja cięcia (dla liczb ≥ 10) dzieli zapis dziesiętny liczby na dwa niepuste fragmenty, np. 14379 można przeciąć na 1 i 4379, 14 i 379, 143 i 79, 1437 i 9 (fragment „02” ma wartość 2). Dla liczby k o parzystej liczbie cyfr cięcie na połowę daje liczbę a (lewa połowa cyfr) i b (prawa połowa).

Napisz w pseudojęzyku lub wybranym języku algorytm, który dla dodatniej liczby całkowitej k o parzystej liczbie cyfr wyznaczy a i b powstałe przez cięcie na połowę (np. 123456 → a = 123, b = 456; 120056 → a = 120, b = 56). Algorytm może operować tylko na liczbach całkowitych i podstawowych operacjach arytmetycznych, bez funkcji wbudowanych (w szczególności bez konwersji na napisy).

def polowy(k):
    dlugosc = 0
    x = k
    while x > 0:
        x = x // 10
        dlugosc = dlugosc + 1
    potega = 1
    for i in range(dlugosc // 2):
        potega = potega * 10
    a = k // potega
    b = k % potega
    return a, b


print(polowy(123456))
print(polowy(120056))

public class Zadanie {

        while (x > 0) {

Treść zadania

Dla liczby całkowitej n ≥ 10 rozważamy wszystkie możliwe cięcia (zob. 2.1) zapisu liczby n². Stopniem Kaprekara liczby n nazywamy liczbę tych cięć, w których suma powstałych dwóch liczb jest mniejsza lub równa n. Przykłady: 89² = 7921 i żadne cięcie nie daje sumy ≤ 89, więc stopień wynosi 0; 2757² = 7601049 — warunek spełniają cięcia 760|1049 i 76|01049, więc stopień wynosi 2. Plik liczby2.txt zawiera 1000 liczb całkowitych z przedziału [10, 30000].

Napisz program, który wyznaczy największy stopień Kaprekara wśród liczb z pliku oraz liczbę, która go ma (jest tylko jedna taka). Odpowiedź zapisz w pliku wyniki2_3.txt. Do testów służy plik liczby2_przyklad.txt.

Python
def stopien_kaprekara(n):
    kwadrat = str(n * n)
    stopien = 0
    for i in range(1, len(kwadrat)):
        a = int(kwadrat[:i])
        b = int(kwadrat[i:])
        if a + b <= n:
            stopien += 1
    return stopien


najlepszy_stopien = -1
najlepsza_liczba = 0
with open("liczby2.txt") as file:
    for wiersz in file:
        n = int(wiersz)
        s = stopien_kaprekara(n)
        if s > najlepszy_stopien:
            najlepszy_stopien = s
            najlepsza_liczba = n
print(najlepszy_stopien)
print(najlepsza_liczba)

import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.List;

public class Zadanie {
    static boolean cyfra(char znak) {
        return znak >= '0' && znak <= '9';
    }

    // liczba różnych cyfr w napisie
    static long rozne(String s) {
        return s.chars().distinct().count();
    }

    public static void main(String[] args) throws Exception {
        String napis = Files.readString(Path.of("dane.txt")).strip();

        // wydzielenie liczb - maksymalnych ciągów cyfr
        List<String> liczby = new ArrayList<>();
        String biezaca = "";
        for (char znak : napis.toCharArray()) {
            if (cyfra(znak)) {
                biezaca += znak;
            } else {
                if (!biezaca.equals("")) {
                    liczby.add(biezaca);
                }
                biezaca = "";
            }
        }
        if (!biezaca.equals("")) {
            liczby.add(biezaca);
        }

        // 3.1
        int ile50 = 0;
        for (String liczba : liczby) {
            if (liczba.startsWith("50")) {
                ile50 += 1;
            }
        }
        System.out.println("3.1 " + ile50);

        // 3.2
        int[] ile = new int[10];
        for (char znak : napis.toCharArray()) {
            if (cyfra(znak)) {
                ile[znak - '0'] += 1;
            }
        }
        int najczestsza = 0;
        for (int c = 1; c < 10; c++) {
            if (ile[c] > ile[najczestsza]) {
                najczestsza = c;
            }
        }
        System.out.println("3.2 " + najczestsza + " " + ile[najczestsza]);

        // 3.3
        List<String> telefony = new ArrayList<>();
        for (String liczba : liczby) {
            if (liczba.length() == 9) {
                telefony.add(liczba);
            }
        }
        System.out.println("3.3");
        for (String telefon : telefony) {
            if (telefon.charAt(0) == '5') {
                System.out.println(telefon);
            }
        }

        // 3.4
        long najmniej = 10;
        for (String telefon : telefony) {
            najmniej = Math.min(najmniej, rozne(telefon));
        }
        System.out.println("3.4");
        for (String telefon : telefony) {
            if (rozne(telefon) == najmniej) {
                System.out.println(telefon);
            }
        }
