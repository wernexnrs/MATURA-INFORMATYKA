Zadanie 1 (podobne tablice). Dla dodatniej liczby n i tablic liczb całkowitych A[1..n], B[1..n] oraz liczby całkowitej 0 ≤ k < n tablice są k-podobne, gdy A[1..k] = B[n-k+1..n] oraz A[k+1..n] = B[1..n-k] (czyli B powstaje z A przez przesunięcie cykliczne; dla k = 0 pierwszy warunek jest zawsze prawdziwy). Liczbę k nazywamy świadectwem podobieństwa.

  • 1.1 — uzupełnij tabelę: czy tablice [1, 2, 3, 4, 5] i [3, 4, 5, 1, 2] są 2-podobne; dla jakiego k tablice [1,1,1,1,3,1,1,1,1] i [3,1,1,1,1,1,1,1,1] są k-podobne; czy tablice [4, 2, 4, 4, 2, 6] i [4, 4, 2, 6, 4, 2] są 1-podobne (np. [4, 7, 1, 4, 5] i [1, 4, 5, 4, 7] są 2-podobne).
  • 1.2 — napisz funkcję czy_k_podobne(n, A, B, k) zwracającą PRAWDA, gdy tablice są k-podobne, i FAŁSZ w przeciwnym razie. Wolno używać tylko operacji arytmetycznych (w tym div i mod), odwołań do elementów tablicy, porównań, instrukcji sterujących, przypisań i własnych funkcji.
  • 1.3 — napisz funkcję czy_podobne(n, A, B) zwracającą PRAWDA, gdy istnieje k (0 ≤ k < n), dla którego tablice są k-podobne, i FAŁSZ w przeciwnym razie (możesz użyć funkcji czy_k_podobne).
Python
def czy_k_podobne(n, A, B, k):
    # A[1..k] = B[n-k+1..n] (tutaj tablice są indeksowane od 0)
    for i in range(k):
        if A[i] != B[n - k + i]:
            return False
    # A[k+1..n] = B[1..n-k]
    for i in range(n - k):
        if B[i] != A[k + i]:
            return False
    return True


def czy_podobne(n, A, B):
    for k in range(n):
        if czy_k_podobne(n, A, B, k):
            return True
    return False

Zadanie 2 (symetryczny ciąg). Procedura dla nieujemnych liczb całkowitych a i b wypisuje ciąg liczb:

Kod
sym(a, b)
    jeżeli a ≠ 0
        sym(a − 1, b + 1)
        wypisz a * b
        sym(a − 1, b + 1)

Przykład: sym(3, 1) wypisuje 3 4 3 3 3 4 3.

  • 2.1 — podaj ciągi wypisane przez sym(3, 3) i sym(4, 1).
  • 2.2 — podaj długość ciągu wypisanego przez sym(5, 1), sym(6, 6) i sym(10, 2020) (dla porównania: sym(3, 2) daje 7 liczb, sym(4, 4) — 15).
Python
wynik = []


def sym(a, b):
    if a != 0:
        sym(a - 1, b + 1)
        wynik.append(a * b)
        sym(a - 1, b + 1)

for a, b in [(3, 3), (4, 1)]:

for a, b in [(3, 2), (4, 4), (5, 1), (6, 6)]:
    wynik = []
    sym(a, b)

Zadanie 4 (pary). Plik pary.txt zawiera 100 wierszy; w każdym liczba całkowita z przedziału [3, 100] i słowo z małych liter alfabetu angielskiego o długości od 1 do 50, oddzielone spacją. Odpowiedzi zapisz w pliku wyniki4.txt, poprzedzając je numerem zadania (dane przykładowe: przyklad.txt, odpowiedzi: odp_przyklad.txt).

Każdą liczbę parzystą z pliku przedstaw jako sumę dwóch liczb pierwszych (mocna hipoteza Goldbacha). W osobnych wierszach, w kolejności z pliku, wypisz liczbę i oba składniki w kolejności niemalejącej, oddzielone spacjami; gdy rozkładów jest kilka, wybierz składniki o największej różnicy (dla 20: 20 3 17).

Dla danych przykładowych: 24 5 19, 6 3 3, 6 3 3.

Python
def czy_pierwsza(x):
    if x < 2:
        return False
    i = 2
    while i * i <= x:
        if x % i == 0:
            return False
        i += 1
    return True


with open("pary.txt") as file:
    for line in file:

Dane z pliku pary.txt (100 par: liczba i słowo z małych liter).

Para (liczba1, słowo1) jest mniejsza od (liczba2, słowo2), gdy liczba1 < liczba2 albo liczby są równe, a słowo1 jest leksykograficznie mniejsze (np. (1, bbbb) < (2, aaa), (3, aaa) < (3, ab)). Spośród par, w których liczba jest równa długości słowa, wypisz najmniejszą (jest jedna taka).

Dla danych przykładowych: 6 abbbbc.

Python
pary = []

with open("pary.txt") as file:
    for line in file:
        liczba, slowo = line.split()
        liczba = int(liczba)
        if liczba == len(slowo):
            pary.append((liczba, slowo))

# krotki porównują się najpierw po liczbie, a przy równości - po słowie
liczba, slowo = min(pary)
print(liczba, slowo)
