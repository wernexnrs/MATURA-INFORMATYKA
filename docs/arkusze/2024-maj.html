Plansza ma n wierszy (numerowanych od góry 1..n) i m kolumn (numerowanych od lewej 1..m); każde pole jest białe albo czarne. Opisuje ją tablica A[1..n][1..m], w której A[i][j] = 1 oznacza pole białe, a 0 — czarne. Lewy górny i prawy dolny róg są zawsze białe. Algorytm korzysta z pomocniczej tablicy logicznej P[1..n][1..m] i zwraca PRAWDA albo FAŁSZ:

Kod
P[1][1] ← PRAWDA
dla i = 1, 2, ..., n wykonuj
    dla j = 1, 2, ..., m wykonuj
        jeżeli A[i][j] = 0
            P[i][j] ← FAŁSZ
        w przeciwnym przypadku
            jeżeli i = 1 oraz j ≠ 1:  P[i][j] ← P[i][j−1]
            jeżeli i ≠ 1 oraz j = 1:  P[i][j] ← P[i−1][j]
            jeżeli i ≠ 1 oraz j ≠ 1:  P[i][j] ← P[i][j−1] lub P[i−1][j]
podaj wynik P[n][m]
  • 1.1 — Podaj wynik algorytmu dla trzech plansz przedstawionych na rysunkach w arkuszu: a) 3 × 3, b) 5 wierszy × 3 kolumny, c) 5 × 5.
  • 1.2 — Podaj przykład planszy (z białymi narożnikami: lewym górnym i prawym dolnym): a) 5 × 5 z co najwyżej 2 czarnymi polami, dla której wynikiem jest FAŁSZ; b) 4 × 4 z co najmniej 9 czarnymi polami, dla której wynikiem jest PRAWDA.
  • 1.3 — Dla kwadratowej planszy n × n podaj największą możliwą liczbę czarnych pól, przy której algorytm zwraca PRAWDA.
Python
def algorytm(A):
    n = len(A)
    m = len(A[0])
    P = [[False] * m for _ in range(n)]
    P[0][0] = True
    for i in range(n):
        for j in range(m):
            if A[i][j] == 0:
                P[i][j] = False
            elif i == 0 and j != 0:
                P[i][j] = P[i][j - 1]
            elif i != 0 and j == 0:
                P[i][j] = P[i - 1][j]
            elif i != 0 and j != 0:
                P[i][j] = P[i][j - 1] or P[i - 1][j]
    return P[n - 1][m - 1]

#include <algorithm>

using Plansza = std::vector<std::vector<int>>;

bool algorytm(const Plansza& A) {
    int n = A.size();
    int m = A[0].size();
    std::vector<std::vector<bool>> P(n, std::vector<bool>(m, false));
    P[0][0] = true;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (A[i][j] == 0) {
                P[i][j] = false;
            } else if (i == 0 && j != 0) {
                P[i][j] = P[i][j - 1];
            } else if (i != 0 && j == 0) {
                P[i][j] = P[i - 1][j];
            } else if (i != 0 && j != 0) {
                P[i][j] = P[i][j - 1] || P[i - 1][j];
            }
        }
    }
    return P[n - 1][m - 1];
}

Algorytm dla nieujemnej liczby całkowitej n oblicza liczbę c (mod i div to reszta i iloraz z dzielenia całkowitego):

Kod
b ← 1
c ← 0
dopóki n > 0 wykonuj
    a ← n mod 10
    n ← n div 10
    jeżeli a mod 2 = 0
        c ← c + b * (a div 2)
    w przeciwnym razie
        c ← c + b
    b ← b * 10

Python
def algorytm(n):
    b = 1
    c = 0
    wykonania = 0
    while n > 0:
        a = n % 10
        n = n // 10
        if a % 2 == 0:
            c = c + b * (a // 2)
        else:
            c = c + b
            wykonania += 1
        b = b * 10
    return c, wykonania

Nieparzystym skrótem dodatniej liczby całkowitej n jest liczba m powstała przez usunięcie z zapisu dziesiętnego n wszystkich cyfr parzystych. Jeśli n ma same cyfry parzyste, skrót nie istnieje. Przykłady: skrót 294762 to 97, skrót 39101 to 3911, skrót 224 nie istnieje.

Napisz (w pseudokodzie lub wybranym języku) funkcję, która dla dodatniej liczby całkowitej n, mającej nieparzysty skrót, wyznacza ten skrót m. Algorytm może operować wyłącznie na liczbach całkowitych i używać tylko podstawowych operacji arytmetycznych (w tym div i mod), porównań, instrukcji sterujących i własnych funkcji — bez funkcji wbudowanych.

def skrot(n):

        cyfra = n % 10
        if cyfra % 2 != 0:
            m = m + cyfra * p
            p = p * 10
        n = n // 10
    return m


for n in [294762, 39101]:
