Zadanie 1. Korale. Rekurencyjna procedura Korale(n) dla dodatniej liczby całkowitej n:

Kod
Korale(n):
    jeżeli n = 1: nawlecz czarny koralik na prawy koniec sznurka; zakończ
    jeżeli n parzyste: Korale(n/2); nawlecz biały koralik na prawy koniec; zakończ
    jeżeli n nieparzyste: Korale((n-1)/2); nawlecz czarny koralik na prawy koniec; zakończ

Podaj wynik działania Korale(n) (ciąg koralików) dla n = 1, 2, 3, 4, 7, 8, 15, 16.

Python · C - czarny koralik, B - bialy koralik
def korale(n):
    if n == 1:
        return "C"
    if n % 2 == 0:
        return korale(n // 2) + "B"
    return korale((n - 1) // 2) + "C"


for n in [1, 2, 3, 4, 7, 8, 15, 16]:
    print(n, korale(n))

Zadanie 2. Bisekcja. Dla funkcji ciągłej na <a, b>, o wartościach różnych znaków na końcach przedziału, liczymy f w środku x = (a+b)/2. Jeśli f(x) = 0, x jest miejscem zerowym; w przeciwnym razie zawężamy przedział do <a, x> lub <x, b> tak, by na końcach znów były różne znaki. Powtarzamy do znalezienia zera lub aż długość przedziału spadnie poniżej dokładności d — wtedy wynikiem jest środek ostatniego przedziału.

Dla f(x) = x³ − x − 2 i przedziału <0, 2>:

  • 2a — wykonaj trzy pierwsze kroki bisekcji, podając w każdym a, b, f(a), f(b), x, f(x) i wybrany nowy przedział (krok 1: a = 0, b = 2, f(a) = −2, f(b) = 4, x = 1, f(x) = −2, więc wybieramy <x, b>).

Bisekcja jak w zadaniu 2. Dane są: przedział domknięty <a, b>, funkcja f ciągła na nim, taka że f(a)·f(b) < 0, oraz dodatnia dokładność d ≤ b − a. Zapisz algorytm wyznaczający metodą bisekcji przybliżenie miejsca zerowego f w <a, b> z dokładnością d.

Python
def bisekcja(f, a, b, d):
    x = (a + b) / 2
    while b - a >= d:
        if f(x) == 0:
            return x
        if f(a) * f(x) < 0:
            b = x
        else:
            a = x
        x = (a + b) / 2
    return x


print(bisekcja(lambda x: x ** 3 - x - 2, 0, 2, 0.0001))

double bisekcja(std::function<double(double)> f, double a, double b, double d) {
    double x = (a + b) / 2;
    while (b - a >= d) {
        if (f(x) == 0) return x;
        if (f(a) * f(x) < 0) b = x;
        else a = x;
        x = (a + b) / 2;
    }
    return x;
}

Zadanie 3. Dla dodatniej liczby całkowitej n:

Kod
jeżeli n = 1: suma ← 1
w przeciwnym razie:
    suma ← 1 + n; i ← n - 1
    dopóki i > 1: suma ← 1 + i * suma; i ← i - 1

Podaj wartość zmiennej suma po zakończeniu algorytmu dla n = 4 i n = 6.

Python
def algorytm(n):
    if n == 1:
        return 1
    suma = 1 + n
    i = n - 1
    while i > 1:
        suma = 1 + i * suma
        i -= 1
    return suma


print(algorytm(4), algorytm(6))

Zadanie 4. Ferma. Na fermie jest początkowo 200 kur. Kilogram paszy kosztuje 1,9 zł, a kura zjada dziennie 0,2 kg. Okres hodowli to dni 1–180; pierwsza niedziela to dzień 7. Codziennie w południe, oprócz niedziel, każda kura znosi 1 jajko, a wszystkie jajka są sprzedawane tego dnia po 0,9 zł. W każdy dzień o nieparzystym numerze po zmroku (po posiłku i sprzedaży) lis zmniejsza stado o 2 kury. Co 30 dni (dzień 30, 60, …) rano, przed posiłkiem, stado powiększa się o 20% (liczbę kupionych kur zaokrąglamy w dół) — kura kosztuje 18 zł. Odpowiedzi do a–c zapisz w kolejnych wierszach pliku ZADANIE4.TXT, poprzedzając każdą literą podpunktu.

  • a) Podaj dzień i porę dnia, w której liczba kur po raz pierwszy ponownie wyniesie dokładnie 200.
  • b) Podaj łączną kwotę wydaną na paszę w ciągu 180 dni.
  • c) Dzienny zysk to przychód ze sprzedaży jajek minus koszt paszy i koszt kur dokupionych tego dnia; realny zysk to suma dotychczasowych dziennych zysków. Podaj, po którym dniu realny zysk po raz pierwszy przekroczy 1500 zł, oraz jaki będzie realny zysk po 180 dniach.
