Zadanie 1. Obliczanie wartości wielomianu. Dla liczb rzeczywistych a0, a1, a2, a3, a4 i x obliczamy W(x) = a0·x⁴ + a1·x³ + a2·x² + a3·x + a4. Sposób 1 liczy każdą potęgę osobno, sposób 2 korzysta ze schematu Hornera: W(x) = x·(x·(x·(x·a0 + a1) + a2) + a3) + a4.

Algorytm (sposób 1):

Kod
W ← 0, i ← 0
dopóki i <= 4 wykonuj:
    sk ← a[i], j ← 4 - i
    dopóki j > 0 wykonuj: sk ← sk*x; j ← j - 1
    W ← W + sk, i ← i + 1

Podaj, ile mnożeń i ile dodawań liczb rzeczywistych wykonuje ten algorytm (bez operacji na zmiennych sterujących i, j).

Python
def sposob1(a, x):
    mnozenia = 0
    dodawania = 0
    W = 0
    i = 0
    while i <= 4:
        sk = a[i]
        j = 4 - i
        while j > 0:
            sk = sk * x
            mnozenia += 1
            j = j - 1
        W = W + sk
        dodawania += 1
        i = i + 1
    return W, mnozenia, dodawania


print(sposob1([1, 2, 3, 4, 5], 2))

Zadanie 2. Algorytm. Dla liczby całkowitej N > 1:

Kod
d ← 2
dopóki N ≥ d wykonuj:
    jeżeli N mod d = 0 to: wypisz d; N ← N div d
    w przeciwnym razie d ← d + 1
  • 2a — podaj liczby wypisane przez algorytm dla N = 36, N = 120 i N = 675.
  • 2c — podaj, ile liczb zostanie wypisanych dla N = 2100.

(W podpunkcie 2b należało wskazać, że algorytm wypisuje czynniki pierwsze liczby N.)

Python
def algorytm(N):
    wypisane = []
    d = 2
    while N >= d:
        if N % d == 0:
            wypisane.append(d)
            N = N // d
        else:
            d = d + 1
    return wypisane


for N in [36, 120, 675]:
    print(N, algorytm(N))

print(len(algorytm(2 ** 100)))

// 2^100 nie mieści się w long long, więc używamy 128-bitowej liczby bez znaku
// (rozszerzenie kompilatora GCC/Clang)
using duza = unsigned __int128;

std::vector<long long> algorytm(duza N) {
    std::vector<long long> wypisane;
    duza d = 2;
    while (N >= d) {
        if (N % d == 0) {
            wypisane.push_back((long long)d);
            N = N / d;
        } else {
            d = d + 1;
        }
    }
    return wypisane;
}

int main() {

        std::println("{} {}", N, algorytm(N));
    }
    std::println("{}", algorytm(duza(1) << 100).size());
}
Java 25
import java.math.BigInteger;
import java.util.ArrayList;
import java.util.List;

public class Zadanie {
    // 2^100 nie mieści się w long, więc liczymy na BigInteger
    static List<BigInteger> algorytm(BigInteger N) {
        var wypisane = new ArrayList<BigInteger>();
        var d = BigInteger.TWO;
        while (N.compareTo(d) >= 0) {
            if (N.mod(d).signum() == 0) {
                wypisane.add(d);
                N = N.divide(d);
            } else {
                d = d.add(BigInteger.ONE);
            }
        }
        return wypisane;
    }

    public static void main(String[] args) throws Exception {
        for (int N : new int[]{36, 120, 675}) {
            System.out.println(N + " " + algorytm(BigInteger.valueOf(N)));
        }
        System.out.println(algorytm(BigInteger.TWO.pow(100)).size());
    }
}

Odpowiedź: a) 36 → 2, 2, 3, 3; 120 → 2, 2, 2, 3, 5; 675 → 3, 3, 3, 5, 5; b) czynniki pierwsze liczby N; c) dla N = 2100 zostanie wypisanych 100 liczb

Algorytm rozkładu na czynniki jak w zadaniu 2. Zapisz algorytm, który dla liczby całkowitej N > 1 wypisze jej rozkład na czynniki pierwsze w postaci par a, b, gdzie a — czynnik pierwszy, b — liczba jego wystąpień w rozkładzie.

Przykład: dla 225 = 3·3·5·5 wypisujemy pary 3, 2 i 5, 2; dla 784 — pary 2, 4 i 7, 2.

Python
def czynniki_pary(N):
    a = 2
    b = 0
    while N >= a:
        if N % a == 0:
            b = b + 1
            N = N // a
        else:
            if b > 0:
                print(a, b)
            a = a + 1
            b = 0
    print(a, b)
