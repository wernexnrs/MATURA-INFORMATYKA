Podaj algorytm, który dla danej liczby całkowitej k ≥ 0 wyznacza resztę z dzielenia 2ᵏ przez 10 (np. dla k = 15 wynikiem jest 8). Oceniana jest poprawność i złożoność czasowa (liczba operacji arytmetycznych; operacje na liczbach całkowitych wykonują się w czasie stałym).

Python
def ostatnia_cyfra(k):
    # Dane: k >= 0, Wynik: reszta z dzielenia 2^k przez 10 (stała liczba operacji)
    if k == 0:
        return 1
    reszta = k % 4
    if reszta == 0:
        return 6
    if reszta == 1:
        return 2
    if reszta == 2:
        return 4
    return 8


print(ostatnia_cyfra(15))
print(all(ostatnia_cyfra(k) == 2 ** k % 10 for k in range(1000)))

Podaj algorytm obliczania aⁿ, gdzie a jest liczbą całkowitą, a n jest potęgą dwójki (n = 2ᵏ, k ≥ 0). Oceniana jest złożoność czasowa w zależności od n. Wskazówka: aⁿ = a^(n/2) · a^(n/2) dla n > 1.

Python
def potega(a, n):
    # Dane: a - liczba całkowita, n = 2^k, Wynik: a^n (log2(n) mnożeń)
    p = a
    while n > 1:
        p = p * p
        n = n // 2
    return p


print(potega(3, 8), 3 ** 8)
print(potega(2, 1024) == 2 ** 1024)

// C++ nie ma wbudowanych dużych liczb, a 2^1024 nie mieści się w long long.
// Duża liczba = wektor cyfr dziesiętnych od najmniej znaczącej.
using Duza = std::vector<int>;

Duza pomnoz(const Duza& a, const Duza& b) {
    Duza wynik(a.size() + b.size(), 0);
    for (size_t i = 0; i < a.size(); i++)
        for (size_t j = 0; j < b.size(); j++)
            wynik[i + j] += a[i] * b[j];
    for (size_t i = 0; i + 1 < wynik.size(); i++) { // przeniesienia
        wynik[i + 1] += wynik[i] / 10;
        wynik[i] %= 10;
    }
    while (wynik.size() > 1 && wynik.back() == 0) wynik.pop_back();
    return wynik;
}

Duza potega(Duza a, long long n) {
    // Dane: a - liczba całkowita, n = 2^k, Wynik: a^n (log2(n) mnożeń)
    Duza p = a;
    while (n > 1) {
        p = pomnoz(p, p);
        n = n / 2;
    }
    return p;
}

long long potega_mala(long long a, long long n) {

}

Zadanie 2 (słowa). Napis to niepusty ciąg liter z alfabetu {a, b}. Napis 2-regularny: każdy napis jednoliterowy jest 2-regularny, a jeśli w jest 2-regularny, to ww też; innych nie ma. Procedura 2REG(w):

Kod
1. jeśli |w| = 1 → TAK
2. jeśli |w| > 1 i |w| nieparzyste → NIE
3. jeśli |w| > 1 i |w| parzyste:
   3.1 podziel w na połowy w1, w2 (w = w1w2)
   3.2 jeśli w1 ≠ w2 → NIE
   3.3 wynik = 2REG(w1)

Wypisz parametry wszystkich wywołań rekurencyjnych 2REG i wynik dla napisów: aabbaabb, aaaaaaaa, bbbbbbbbbbbbbbbbbbbb (np. dla abab: abab → NIE).

Python
def reg2(w):
    print(w)
    if len(w) == 1:
        return "TAK"
    if len(w) % 2 == 1:
        return "NIE"
    polowa = len(w) // 2
    w1 = w[:polowa]
    w2 = w[polowa:]
    if w1 != w2:
        return "NIE"
    return reg2(w1)


for napis in ["aabbaabb", "aaaaaaaa", "bbbbbbbbbbbbbbbbbbbb"]:

Napisy 3-regularne: każdy napis jednoliterowy jest 3-regularny; jeśli w jest 3-regularny, to napisy wxw oraz wwx (x — dowolny napis nad {a, b} o tej samej długości co w) też są 3-regularne; innych nie ma. Np. a, aba, abaabaaaa są 3-regularne, a aaaabaaba nie jest.

Napisz algorytm, który dla danego napisu w (|w| ≥ 1) odpowiada TAK, jeśli w jest 3-regularny, i NIE w przeciwnym razie.

Python
def reg3(w):
    # Dane: napis w nad alfabetem {a, b}, Wynik: TAK, jeśli w jest 3-regularny
    n = len(w)
    if n == 1:
        return "TAK"
    if n % 3 != 0:
        return "NIE"
    d = n // 3
    w1 = w[:d]
    w2 = w[d:2 * d]
    w3 = w[2 * d:]
    if w1 == w2 or w1 == w3:
        return reg3(w1)
    return "NIE"


for napis in ["a", "aba", "abaabaaaa", "aaaabaaba"]:

def podziel_mandaty(glosy, mandaty):
    # uproszczona metoda d'Hondta: X = v / (s + 1)
    s = [0] * len(glosy)
    for _ in range(mandaty):
        najlepszy = 0
        for i in range(len(glosy)):
            if glosy[i] / (s[i] + 1) > glosy[najlepszy] / (s[najlepszy] + 1):
                najlepszy = i
        s[najlepszy] += 1
    return s

def utworz_haslo(w):
    # najdłuższy palindrom będący początkiem słowa w
    dlugosc = len(w)
