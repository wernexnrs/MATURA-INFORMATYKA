Szyfr przestawieniowy: tekst wpisujemy wierszami do kwadratowej tablicy n × n, a szyfrogram odczytujemy kolumnami od lewej do prawej. Wymiar n to najmniejsza liczba, przy której cały tekst mieści się w tablicy; wolne pola uzupełnia się znakami odstępu (oznaczanymi _).

Przykład: ALGORYTM_PRZESTAWIENIOWY (24 znaki) → tablica 5 × 5 → AYRAILTZWOGMEIWO_SEYRPTN_.

Podaj wzór (lub algorytm) wyznaczający liczbę wierszy i kolumn tablicy dla tekstu o długości d znaków.

Python
from math import ceil, sqrt


def wymiar(d):
    # najmniejsze n, dla którego n * n >= d, czyli n = sufit(pierwiastek(d))
    n = ceil(sqrt(d))
    while n * n < d:  # zabezpieczenie przed błędem zaokrąglenia
        n += 1
    return n


print(wymiar(24), wymiar(25), wymiar(26))

Szyfr przestawieniowy z zadania 1a (tekst wpisywany wierszami do tablicy n × n, odczytywany kolumnami).

  • 1b — Rozszyfruj cytat z Sokratesa zaszyfrowany tą metodą — szyfrogram (64 znaki, czyli tablica 8 × 8) jest podany w arkuszu.
  • 1c — Zapisz algorytm szyfrujący tą metodą. Dane: d — długość tekstu, tekst[1..d] — znaki tekstu. Wynik: s — długość szyfrogramu, szyfr[1..s] — znaki szyfrogramu.
Python
from math import ceil, sqrt


def szyfruj(tekst):
    d = len(tekst)
    n = ceil(sqrt(d))
    while n * n < d:
        n += 1
    s = n * n
    tekst = tekst + "_" * (s - d)  # puste pola uzupełniamy znakami odstępu
    szyfr = ""
    for kolumna in range(n):  # odczyt kolumnami
        for wiersz in range(n):
            szyfr += tekst[wiersz * n + kolumna]
    return szyfr


# c) przykład z treści
print(szyfruj("ALGORYTM_PRZESTAWIENIOWY"))

// std::string przechowuje bajty UTF-8, a polskie litery (np. Ę, Ą) zajmują po 2 bajty,
// dlatego najpierw dzielimy tekst na pojedyncze znaki - każdy jako osobny napis
std::vector<std::string> znaki(const std::string& tekst) {
    std::vector<std::string> wynik;
    size_t i = 0;
    while (i < tekst.size()) {
        unsigned char bajt = tekst[i];
        size_t dlugosc = 1;
        if (bajt >= 0xF0) dlugosc = 4;
        else if (bajt >= 0xE0) dlugosc = 3;
        else if (bajt >= 0xC0) dlugosc = 2;
        wynik.push_back(tekst.substr(i, dlugosc));
        i += dlugosc;
    }
    return wynik;
}

std::string szyfruj(const std::string& napis) {

        for (int wiersz = 0; wiersz < n; wiersz++) {

    }
    return szyfr;
}

W tablicy a[1..1023] zapisano ciąg zer i jedynek tak, że wszystkie zera poprzedzają jedynki (mogą wystąpić same zera albo same jedynki). Dany jest niepełny algorytm liczenia zer:

Kod
liczba_zer ← 0
l ← 1, p ← 1023
dopóki l ≤ p wykonuj
    s ← (l + p) div 2
    jeżeli a[s] = 1 to p ← s − 1
    w przeciwnym przypadku
        liczba_zer ← liczba_zer + .....
        l ← .....
  • 2a — Uzupełnij brakujące wyrażenia tak, aby algorytm zawsze poprawnie liczył zera.
  • 2b — Ile razy wykonywane jest przypisanie s ← (l + p) div 2 w każdym przebiegu algorytmu? Uzasadnij.
Python
def liczba_zer(a):
    # a[1..1023], a[0] nieużywane - indeksy jak w zadaniu
    przypisania_s = 0
    zera = 0
    l, p = 1, len(a) - 1
    while l <= p:
        s = (l + p) // 2
        przypisania_s += 1
        if a[s] == 1:
            p = s - 1
        else:
            zera = zera + (s - l + 1)  # zera na pozycjach l..s
            l = s + 1
    return zera, przypisania_s


# sprawdzenie dla wszystkich możliwych tablic (k zer, potem jedynki)
liczby_przypisan = set()
for k in range(1024):

    zera, przypisania_s = liczba_zer(a)
    if zera != k:
        print("błąd dla", k)
    liczby_przypisan.add(przypisania_s)
print(liczby_przypisan)

import java.util.*;

public class Zadanie {
    static int[] liczbaZer(int[] a) {
        // a[1..1023], a[0] nieużywane - indeksy jak w zadaniu
        int przypisaniaS = 0;
        int zera = 0;
        int l = 1, p = a.length - 1;
        while (l <= p) {
            int s = (l + p) / 2;
            przypisaniaS += 1;
            if (a[s] == 1) {
                p = s - 1;
            } else {
                zera = zera + (s - l + 1); // zera na pozycjach l..s
                l = s + 1;
            }
        }
        return new int[]{zera, przypisaniaS};
    }

    public static void main(String[] args) throws Exception {
        // sprawdzenie dla wszystkich możliwych tablic (k zer, potem jedynki)

        for (int k = 0; k < 1024; k++) {

            for (int i = k + 1; i < 1024; i++) {
                a[i] = 1;
            }
            int[] wynik = liczbaZer(a);
            if (wynik[0] != k) {
                System.out.println("błąd dla " + k);

def czy_anagram(a, b):
    return sorted(a) == sorted(b)


with open("anagram.txt") as file, open("odp_4b.txt", "w") as wynik:
    for line in file:
        slowa = line.split()

import java.io.*;

public class Zadanie {

import java.nio.file.*;
import java.util.*;

public class Zadanie {
    public static void main(String[] args) throws Exception {
        var dekady = new LinkedHashMap<String, Integer>();
        for (String d : List.of("50", "60", "70", "80", "90")) {
            dekady.put(d, 0);
        }
        for (String linia : Files.readAllLines(Path.of("pesel.txt"))) {
            String dekada = linia.charAt(0) + "0";
            dekady.put(dekada, dekady.get(dekada) + 1);
        }
        int wszyscy = 0;
        for (int ile : dekady.values()) {
            wszyscy += ile;
        }
        for (var e : dekady.entrySet()) {
            double procent = (double) e.getValue() / wszyscy * 100;
            // Locale.ROOT - kropka dziesiętna niezależnie od ustawień systemu
            System.out.println(String.format(Locale.ROOT, "%s-te %d %.1f%%", e.getKey(), e.getValue(), procent));
        }
    }
}
