Zadanie 1 (suma silni). Silnia: 1! = 1, n! = (n−1)!·n dla n > 1. Funkcja ss(n) = 1! + 2! + ... + n! dla n ≥ 1.

Podaj, ile mnożeń trzeba wykonać, aby obliczyć ss(3), ss(4) oraz ss(n), jeśli każdą silnię we wzorze liczymy osobno, wprost z definicji.

Python
def ss_wprost(n):
    # każdą silnię liczymy osobno i liczymy mnożenia
    mnozenia = 0
    suma = 0
    for k in range(1, n + 1):
        silnia = 1
        for i in range(2, k + 1):
            silnia *= i
            mnozenia += 1
        suma += silnia
    return suma, mnozenia


for n in [3, 4, 10]:
    print(n, *ss_wprost(n), n * (n - 1) // 2)

Czynnik 2 występuje w n−1 silniach sumy ss(n) = 1! + ... + n!, czynnik 3 w n−2 silniach itd. Wykorzystaj to i przekształć wzór (schemat zagnieżdżony, np. ss(3) = 1 + 2·(1 + 3), ss(4) = 1 + 2·(1 + 3·(1 + 4))), tak aby ss(n) dało się policzyć wykonując dokładnie n−2 mnożenia dla n ≥ 2. Uzupełnij tabelę dla ss(4), ss(5), ss(n), a następnie zapisz algorytm obliczania ss(n) według tego wzoru wraz ze specyfikacją.

Python
def ss(n):
    # Dane: n - liczba naturalna > 0
    # Wynik: ss = 1! + 2! + ... + n!
    # ss(n) = 1+2*(1+3*(1+...(n-2)*(1+(n-1)*(1+n))...))
    if n == 1:
        return 1
    wynik = 1 + n
    i = n - 1
    while i > 1:
        wynik = 1 + i * wynik
        i -= 1
    return wynik


for n in range(1, 8):
    print(n, ss(n))

Zadanie 2 (liczby pierwsze). Dany jest algorytm sita Eratostenesa: dla N ≥ 2 wypełnia tablicę T[2..N] tak, że T[i] = 0, gdy i jest pierwsza, i T[i] = 1, gdy złożona (dla kolejnych i z T[i] = 0 ustawia T[j] := 1 dla j = 2i, 3i, ... ≤ N).

Dane są liczba naturalna M ≥ 1 i tablica A[1..M] liczb z przedziału [2, N]. Korzystając z sita, zaprojektuj algorytm (ze specyfikacją) wyznaczający te liczby z [2, N], które nie są podzielne przez żadną z liczb A[1], ..., A[M].

Python
def niepodzielne(N, A):
    # Dane: N > 1, tablica A liczb z przedziału [2, N]
    # Wynik: T[i] = 0 wtedy i tylko wtedy, gdy i nie dzieli się przez żadną z liczb A
    T = [0] * (N + 1)
    for liczba in A:
        j = liczba
        while j <= N:
            T[j] = 1
            j += liczba
    return [i for i in range(2, N + 1) if T[i] == 0]


print(niepodzielne(30, [2, 3]))

#include <vector>

std::vector<int> niepodzielne(int N, const std::vector<int>& A) {
    // Dane: N > 1, tablica A liczb z przedziału [2, N]
    // Wynik: T[i] = 0 wtedy i tylko wtedy, gdy i nie dzieli się przez żadną z liczb A
    std::vector<int> T(N + 1, 0);
    for (int liczba : A)
        for (int j = liczba; j <= N; j += liczba)
            T[j] = 1;
    std::vector<int> wynik;
    for (int i = 2; i <= N; i++)
        if (T[i] == 0) wynik.push_back(i);
    return wynik;
}

int main() {
    std::println("{}", niepodzielne(30, {2, 3})); // wypisuje [5, 7, 11, ...]
}

def czy_pierwsza(L):
    j = 2
    pierwsza = True
    while j * j <= L and pierwsza:
        pierwsza = L % j != 0
        j += 1
    return "Tak" if pierwsza else "Nie"


for L in [2, 9, 13, 97, 100]:

Dla figury F(C) z zadania 5 wyznacz najmniejsze naturalne C, dla którego wewnątrz F(C) (brzeg należy do wnętrza) mieści się prostokąt 100 × 26 o wierzchołkach w punktach o współrzędnych całkowitych, o bokach równoległych do osi, z dłuższymi bokami równoległymi do OX. W pliku figura.txt podaj C i współrzędne wierzchołków prostokąta.

Python
import math


def f(x):
    return -x * x / 50


def g(x):
    return 1 + x * x / 100 - x / 200


# dla x >= 0 funkcja f maleje, a g rośnie dla x >= 0.25,
# więc na przedziale [x0, x0+100] największe f jest w x0, a najmniejsze g w max(x0, 0.25)
znalezione = False
C = 100
while not znalezione:
    for x0 in range(0, C - 100 + 1):
        dol = math.ceil(f(x0))
        gora = math.floor(g(max(x0, 0.25)))
        if gora - dol >= 26:
            znalezione = True
            print("C =", C)
            for y0 in range(dol, gora - 26 + 1):
                print((x0, y0), (x0 + 100, y0), (x0, y0 + 26), (x0 + 100, y0 + 26))
            break
    if not znalezione:
        C += 1
