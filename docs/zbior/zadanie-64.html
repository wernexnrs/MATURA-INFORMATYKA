Zadanie 64. Obrazki

ZBIÓR ZADAŃDANEROZWIĄZANIA

Każdy obrazek w pliku to 21 wierszy: 20 wierszy po 20 pikseli + bit parzystości wiersza oraz ostatni wiersz z 20 bitami parzystości kolumn. Obrazki oddzielone są pustym wierszem.

64.1

PythonC++23Java 25
Treść zadania

Bit parzystości ciągu zer i jedynek wynosi 0, gdy jedynek jest parzyście wiele, a 1 w przeciwnym razie. Czarno-biały obrazek n × n zapisujemy jako n wierszy po n pikseli (0 — biały, 1 — czarny); na końcu każdego wiersza dopisany jest jego bit parzystości, a pod obrazkiem — wiersz bitów parzystości kolejnych kolumn. Bity parzystości nie należą do obrazka. Plik dane_obrazki.txt zawiera 200 obrazków 20 × 20, oddzielonych pustym wierszem. Odpowiedzi zapisz w pliku wyniki_obrazki.txt, każdą od nowego wiersza, poprzedzoną numerem zadania.

Obrazek jest rewersem, jeśli ma więcej pikseli czarnych niż białych. Podaj, ile obrazków w pliku jest rewersami, oraz największą liczbę czarnych pikseli w jednym obrazku.

Python
obrazki = []

with open("dane_obrazki.txt") as file:
    wiersze = file.read().split()  # puste wiersze znikają
for i in range(0, len(wiersze), 21):
    obrazki.append(wiersze[i:i + 21])

rewersy = 0
najwiecej_czarnych = 0
for obrazek in obrazki:
    czarne = 0
    for wiersz in obrazek[:20]:
        czarne += wiersz[:20].count("1")
    if czarne > 400 - czarne:
        rewersy += 1
    najwiecej_czarnych = max(najwiecej_czarnych, czarne)

print(rewersy, najwiecej_czarnych)

#include <algorithm>
#include <fstream>
#include <print>
#include <string>

int main() {
    // wczytujemy słowo po słowie - puste wiersze znikają
    std::ifstream plik("dane_obrazki.txt");
    std::vector<std::string> wiersze;
    std::string s;
    while (plik >> s) {
        wiersze.push_back(s);
    }
    std::vector<std::vector<std::string>> obrazki;
    for (size_t i = 0; i < wiersze.size(); i += 21) {
        obrazki.push_back(std::vector<std::string>(wiersze.begin() + i, wiersze.begin() + i + 21));
    }

    int rewersy = 0;
    int najwiecej_czarnych = 0;
    for (const auto& obrazek : obrazki) {
        int czarne = 0;
        for (int w = 0; w < 20; w++) {
            czarne += std::count(obrazek[w].begin(), obrazek[w].begin() + 20, '1');
        }
        if (czarne > 400 - czarne) {
            rewersy += 1;
        }
        najwiecej_czarnych = std::max(najwiecej_czarnych, czarne);
    }

    std::println("{} {}", rewersy, najwiecej_czarnych);
}

                    if (obrazek[w].charAt(k) == '1') {
                        czarne++;
                    }
                }
            }
            if (czarne > 400 - czarne) {
                rewersy += 1;
            }
            najwiecejCzarnych = Math.max(najwiecejCzarnych, czarne);
        }

        System.out.println(rewersy + " " + najwiecejCzarnych);

}

Treść zadania

Dane jak w zadaniu 64.1 (200 obrazków 20 × 20 z bitami parzystości w pliku dane_obrazki.txt).

Obrazek n × n jest rekurencyjny, jeśli n jest parzyste, a obrazek składa się z czterech kopii tego samego obrazka o rozmiarze n/2 × n/2 (cztery ćwiartki są identyczne). Podaj liczbę obrazków rekurencyjnych oraz opis pierwszego z nich w pliku — 20 wierszy po 20 pikseli, bez bitów parzystości.

Python
obrazki = []

with open("dane_obrazki.txt") as file:
    wiersze = file.read().split()
for i in range(0, len(wiersze), 21):
    obrazek = []
    for wiersz in wiersze[i:i + 20]:
        obrazek.append(wiersz[:20])  # bez bitów parzystości
    obrazki.append(obrazek)


def czy_rekurencyjny(obrazek):
    for w in range(10):
        for k in range(10):
            piksel = obrazek[w][k]
            if obrazek[w][k + 10] != piksel or obrazek[w + 10][k] != piksel or obrazek[w + 10][k + 10] != piksel:
                return False
    return True


rekurencyjne = []
for obrazek in obrazki:
    if czy_rekurencyjny(obrazek):
        rekurencyjne.append(obrazek)

print(len(rekurencyjne))
for wiersz in rekurencyjne[0]:
    print(wiersz)

Treść zadania

Dane jak w zadaniu 64.1.

Obrazek jest poprawny, jeśli wszystkie jego bity parzystości (wierszy i kolumn) są poprawne. Jest naprawialny, jeśli nie jest poprawny, ale ma co najwyżej jeden błędny bit parzystości wiersza i co najwyżej jeden błędny bit parzystości kolumny. Pozostałe obrazki są nienaprawialne. Podaj liczbę obrazków poprawnych, naprawialnych i nienaprawialnych oraz największą liczbę błędnych bitów parzystości w jednym obrazku.

Python

def bledne_bity(obrazek):
    bledne_wiersze = []
    bledne_kolumny = []
    for w in range(20):
        if obrazek[w][:20].count("1") % 2 != int(obrazek[w][20]):

    for k in range(20):
        jedynki = 0
        for w in range(20):
            jedynki += int(obrazek[w][k])
        if jedynki % 2 != int(obrazek[20][k]):
            bledne_kolumny.append(k)
    return bledne_wiersze, bledne_kolumny

Dane jak w zadaniu 64.1; definicje jak w zadaniu 64.3.

Obrazek naprawialny można poprawić, zmieniając jedną wartość: jeśli błędne są bity parzystości i-tego wiersza i j-tej kolumny, zmieniamy j-ty piksel w i-tym wierszu; jeśli błędny jest tylko jeden bit parzystości (wiersza albo kolumny), zmieniamy ten bit. Podaj numery wszystkich obrazków naprawialnych (obrazki numerujemy od 1), a przy każdym numer wiersza i kolumny wartości, którą trzeba zmienić.

def bledne_bity(obrazek):

    bledne_kolumny = []
    for w in range(20):
        if obrazek[w][:20].count("1") % 2 != int(obrazek[w][20]):
            bledne_wiersze.append(w)

            jedynki += int(obrazek[w][k])

for numer in range(len(obrazki)):
    bledne_wiersze, bledne_kolumny = bledne_bity(obrazki[numer])

    if len(bledne_wiersze) > 1 or len(bledne_kolumny) > 1:

    kolumna = bledne_kolumny[0] + 1 if bledne_kolumny else 21
    print(numer + 1, wiersz, kolumna)
